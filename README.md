# 步序

个人成长与行动工作台 Demo。

## 启动

需要 Node.js 20 或更新版本。无需安装依赖。

```sh
npm run dev
```

打开 [本地工作台](http://127.0.0.1:4177)。首次打开带有示例数据。可在「设置 → 清空工作台」从空白开始。

## 试用路径

1. 建立方向、阶段目标和项目，为项目添加可执行的任务。
2. 从任务池选出最多三项今日重点，在首页开始或完成任务。
3. 在成长时间线查看完成记录，写每日复盘，并把下一步加入任务池。
4. 在收集箱记下想法，再整理成笔记、任务或项目。

业务数据保存在当前浏览器，可在设置导出 JSON。此 Demo 面向本机单用户使用。

## 连接模型

在「设置 → AI 服务」填写服务商的 HTTPS Base URL、模型 ID 和 API Key，测试通过后即可使用。Base URL 填到 API 根路径，例如以 `/v1` 结尾的地址。密钥只保存在本地 Node.js 进程内存，重启服务后重新连接。生成建议时会把弹窗列出的业务上下文发送给模型，新增项目和任务须手动确认。
