## 步序（personalDesk）· 网页注册入口

- 项目是单账号设计（`scripts/account.mjs` 只允许初始化一个用户），因此注册实现为「首次创建账号」：`users` 表为空时才开放。
- 新增 `src/routes/register/+page.server.ts`、`+page.svelte`；注册后自动建立会话并跳 `/`。已有账号访问 `/register` 重定向 `/login`，已登录重定向 `/`。
- 服务端：`src/lib/server/auth/session.ts` 抽出 `establish()` 复用建会话逻辑，新增 `createAccount()`（账号 `^[a-z0-9_.-]{1,64}$`、密码 ≥12 字符且 ≤512 字节、两次一致）。
- 数据层：`auth-queries.mjs` 新增 `hasAccount()` 与 `register()`（事务内判空 + 写 users/preferences/savings），`db/index.ts` 的 `Methods` 同步声明。
- 登录页 `load` 返回 `hasAccount`，无账号时显示「创建账号」链接，底部链接样式 `.login-alt` 加入 `app.css`；`.login-page` 从 `place-items: center` 改为 `align-content: center; justify-items: center`，避免矮屏下卡片被裁。
- 验证：`svelte-check` 0 错误；`vitest` 8 项全过（需用 Node 24.15.0，本机默认 Node 22 的 SQLite 3.51.2 会被 `storage.mjs` 版本检查拒绝）；curl 覆盖注册成功/密码过短 422/重复注册 409/注册后登录 303。
