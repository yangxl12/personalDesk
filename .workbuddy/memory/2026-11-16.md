## 启动 dev server 的 Node 版本坑（修正）

- `C:\nvm4w\nodejs` 是 nvm4w 的动态符号链接，指向 `nvm current` 版本，**不可靠**：今天它就是 22.22.2，导致 `openDatabase()` 抛 `Unsupported SQLite version: 3.51.2`，登录页 500、日志只报「数据服务暂不可用」。
- 固定路径是 `D:\nvm\v24.18.0`（`nvm root` = `D:\nvm`），其内置 SQLite 为 3.53.1，通过 `storage.mjs` 的 `>=3.51.3 && !==3.52` 校验。
- 正确启动方式：`export PATH="/d/nvm/v24.18.0:$PATH"` 后跑 `./node_modules/.bin/vite dev --host 0.0.0.0 --port 6173 --strictPort`。
- 排查提示：`process.versions.sqlite` 可快速确认内置 SQLite 版本；`netstat -ano | grep :6173` 查残留进程，旧 vite 进程会在 shell 退出后继续监听端口。
