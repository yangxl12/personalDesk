## 思考卡片正文超出 15 行折叠 + 底部箭头展开

- 需求：正文超过 15 行时卡片底部给一个向下箭头，点开看全文、箭头转向上，再点收起；没超 15 行不出现箭头。
- `NoteCard.svelte`：`VISIBLE_LINES = 15`，`ResizeObserver` 量 Markdown 根节点（`.md` 在裁切容器里仍按全文排版，展开与否 `offsetHeight` 都是全文高），行高取 `getComputedStyle(inner).lineHeight`，算出 `cap = 15 * lineHeight`、`full = inner.offsetHeight`；`clipped = full - cap > 2` 才渲染 `.note-toggle`，`expanded` 控制 `aria-expanded`（箭头靠 CSS 旋转 180°）。
- 高度走 CSS 变量：`.note-body { max-height: var(--note-cap, 322.5px); transition: max-height .42s var(--ease) }`，`.expanded { max-height: var(--note-full, none) }`，展开/收起都有过渡；没量到之前用同样的兜底值，不会先闪一帧全文。
- `.note-grid` 加 `align-items: start`：否则展开一张卡会把同排邻居一起拉高成大片空白。
- 翻译补了两条：展开全部 / 收起。
- 验证：`svelte-check`（Markdown.svelte 的 24 个既有报错与本次无关）、unit 5/5；CDP 直灌 IndexedDB 造 40 行 + 3 行两条笔记，实测 cap=323px、长笔记有箭头 / 短笔记没有、点击后 client 323→1153 且 `matrix(-1,0,0,-1,0,0)`、再点回 323。
