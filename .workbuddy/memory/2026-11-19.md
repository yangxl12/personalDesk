## 弹窗改实色 + 打开时锁底页滚动（commit bb837d3）

- **不透明**：新增 `--dialog-bg` / `--panel` 两个实色变量（亮 `#fcfbff` / `#f3f2fb`，暗 `#17162a` / `#232138`，system 暗色块同步），`dialog` 去掉 `backdrop-filter` 和半透明的 `--glass-strong`，边框换 `--line-strong`；弹窗内输入框、下拉、类型切换按钮、任务列表、月份选择原先的 `--glass-2` 全部换成 `--panel`，否则在实色底上还是发虚。遮罩只加深到 .48（亮）保留轻微 blur。
- **锁滚**：新增 `src/lib/scroll-lock.ts`，引用计数 + `body{position:fixed;top:-scrollY;width:100%;overflow:hidden}`，按滚动条差值补 `paddingRight`，解锁时先 `void body.offsetHeight` 强制重排再 `scrollTo`（不重排文档高度还是锁着的值，会被夹回顶部）。
- **接入**：`Editor`、`GoalEditor`、`Ledger` 三个组件的 `onMount` 直接 `return lockScroll()`，靠 Svelte 的销毁回调解锁；收支记录里再开「记一笔」是两层 dialog，计数保证关掉内层后底层仍锁定。
- **CSS 兜底**：`dialog` 加 `overflow-y:auto; overscroll-behavior:contain`，`.ledger-body` / `.task-picker-list` 也加 `overscroll-behavior:contain`，防边界滚动链。
- **验证**：CDP（`%TEMP%\pd-shot\modal.mjs`、`form.mjs`）实测 1440 / 390 / 暗色三态：dialog 计算背景为实色、`backdrop-filter:none`、打开时 `body` fixed 且 `document.scrollingElement.scrollTop` 恒 0，关窗后 `scrollY` 从 150 准确还原到 150，嵌套两层关内层仍锁定。
