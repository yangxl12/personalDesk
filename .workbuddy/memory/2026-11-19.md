## 设置页合并为单卡片单列（commit e248efe）

- **结构**：去掉 `.settings-grid` 双列网格和四张 `.card settings-card`，外层换成一个 `.card.settings-panel`，内含 4 个 `.settings-block`（AI 设置 / 个人偏好 / 安装到桌面 / 数据管理），相邻块用 `border-top: 1px` 分隔。页面 `max-width: 620px` + `margin-inline: auto` 居中，桌面端不再左右分栏。
- **组件根节点**：`ModelSettings`、`PwaSettings`、`DataSettings` 的 `<section>` 从 `card settings-card` 改为 `settings-block`；`DataSettings` 的 `.data-card { grid-column: 1/-1 }` 和 `.data-actions` 的 `auto-fit minmax(252px,1fr)` 一并删掉，导出/导入固定单列上下排（620 宽下两列会挤到折行）。
- **小屏**：`@container (max-width: 515px)` 里补 `.card.settings-panel { padding: 0 }`（否则 `.card { padding: 18px }` 会覆盖导致双层内边距）+ `.settings-block { padding: 18px }`。
- **验证**：CDP 截图过了桌面 1440 / 移动 390 / 暗色 / 展开添加模型表单四种状态。`.section-head` 底边线在四种分组里都在，模型编辑态是嵌套 `.model-editor` 面板，带边框属有意保留。
