上一版用 `clip-path` 按 `atStart/atEnd` 收边，方向错了：`clip-path` 的裁剪线正好落在卡片左右边缘，卡片 24px 圆角被切直角；底部只留 14/20px，`--shadow` 的 18px 偏移 + 模糊尾超出这条线，卡片下方出现一条水平分割线。移动端 gutter 只有 15px，靠外扩一格 gutter 永远不够。

- **上下**：`.home-slide .goal-board` padding-block 20→40（移动端 14→36），`margin-block` 同步取负。

## 财务卡时段显示 + 悬浮按钮外溢光带（本次）

- **时段文字被截断**：根因是原生 `<input type="month">` 在中文 locale 下渲染成「2026年11月」，卡片宽度不够就只剩「2026年1」。改成自定义 `period-label`（`Intl.DateTimeFormat` 产出：中文 `2026年11月` / `2026年11月19日`，英文 `Nov 2026` / `Nov 19, 2026`）+ 原生控件做 `opacity: 0` 覆盖层，点击调 `showPicker()`（直接点文字区浏览器只聚焦不弹日历）；年模式保留 4 位 number input + 「年」后缀。
- **CSS**：`.period-value` 去掉固定 `min-width` 按内容撑开，`.period-input.year` 2.35em，窄容器下 `.period-nav` 居中、`.period-value` 不拉伸，箭头不再被挤走。
- **顺带修的联动 bug**：`jump` effect 会在 `range` 变化时重跑，深链 `?month=` 留下的 `jump.date` 在切到「日」时被判成范围外，立刻把粒度弹回「月」。加 `applied` 游标，只处理新出现的 jump。
- **暗色下那块灰色柱状物**：不是滚动条。是 `.finance-fab::after` 的扫光条初始 `translateX(-130%)` 滑到了按钮左侧，而 `.finance-fab` 不是 `.button`（`.button` 自带 `overflow: hidden`）没做裁剪，光带就露在外面。给 `.finance-fab` 补 `overflow: hidden`。box-shadow 不受影响，阴影照常溢出。
- **排查手法**（值得复用）：截局部图 → 依次禁 `animation/transition`、`filter/backdrop-filter`、`box-shadow` 都无效 → `documentElement.visibility='hidden'` 后消失说明是 DOM 内容 → 遍历 `getComputedStyle(el, '::after')` 找宿主（伪元素不在 `querySelectorAll` 结果里，`elementFromPoint` 只会返回宿主滚动容器，容易误判成滚动条）。
- **验证**：CDP 390×844 与 1280×900、明暗两色、年/月/日三态截图；svelte-check 0 error，vitest 5 passed。

## 年份显示被裁（本次补丁）

- **真实原因**：`<input type="number">` 只给了 `width: 2.35em`（35.25px），Chrome 下 `clientWidth == scrollWidth` 正好卡住 4 位数字，一点余量都没有；iOS Safari 的数字字形更宽，直接把最后一位裁掉。**能不能显示全完全取决于原生输入框的自适应宽度，不能赌。**
- **改法**：年份跟月/日统一——常态显示自己排的 `label + 单位`（`2026` + `年`，宽度由内容决定），原生 number input 改成 `position:absolute; inset:0` 铺满整块、`opacity:0` 只做交互层；`:focus-within` 时 input 显形、label/单位淡出，宽度是整个容器（54px），4 位数字怎么都放得下。
- **配套**：input 聚焦即 `select()` 全选，直接键入替换；`setYear` 遇到空值/越界把 input 回填成当前年份，不留空壳（测试确认空输入后 label 和 input 都回到 2027）。
- **验证**：390×844 暗色，年/月/日三态 + 聚焦态 + 修改 2026→2027 + 空输入回弹；箭头位置恒为 75px，无跳动；svelte-check 0 error。
